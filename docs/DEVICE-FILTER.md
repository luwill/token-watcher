# 按设备查看用量

仪表盘顶部可选择全部设备、Mac（其他宿主显示本机）、VPS、Windows。默认全部设备；选择单台设备后，累计/今日/近7天、活动图、趋势、模型/工具用量、费用、最近请求、会话列表与钻取、工具活动及CSV按同一设备范围查询。页面始终保留所有设备累计总量。

账户配额、余额、订阅ROI和钱包对账是共享信息，不拆成各设备余额；选择设备时有明确说明。社区排行榜仍使用原有总量口径。Windows仅有用量元数据，因此不包含工具名称与调用内容明细。

## 归属与历史兼容

事件、工具调用、积分账和文件游标新增device字段。原有token数、事件ID、去重键保持不变。已知镜像路径~/.tokenmeter/remote/vps与remote/windows-usage分别标记VPS和Windows；内置本机来源标记local。其他未标记的扩展目录保留未归属，不能仅凭项目名称认作另一台机器。

历史补齐按已保存的工具/会话/文件信息匹配，Codex支持规范化文件键及UUID；Windows投影的文件标识和会话标识不同，仅在Mac已批准的安全元数据文件中补读标识，不读取Windows原始日志。多来源冲突或无法归属的历史仍在总量中，未归属有数据时出现可选项。是否能够归属取决于本机保留的文件和会话元数据。

采集设备上下文只在同步的事务回放期间生效；远端文件异步解析时，本机轮询继续标记本机，避免上下文污染。重复副本沿用原全局去重和已保存设备归属，分区相加不会重复计数。

## API

summary、sessions、session/:id、tool-activity和export.csv支持device=all|local|vps|windows|unknown。缺省all，非法值返回400。summary返回device、devices分区与all_device_totals，最近请求附device。选设备的CSV文件名带设备ID；默认CSV结构与原行为兼容。

## 升级与验证

首次打开 1.9.6 时会在同一个数据库内增加设备元数据列、索引和迁移标记，并尝试归属历史记录；不修改原 token 数、事件 ID 或去重键。无法可靠归属的记录仍显示为未归属。升级前建议保留一致的数据库备份。

历史聚合缓存按数据库连接与设备分区保存。历史写入、外部连接提交、跨日会使缓存失效；事务内现算，回滚不会留下未提交的缓存结果。全部设备概览同样复用历史缓存，避免每次推送重新扫描全部历史。

合成回归覆盖迁移幂等、原字段不变、跨设备去重、异步采集上下文隔离、API/CSV 分区合计、设备快速切换及历史缓存回滚。本地曾使用独立运行目录的安装，应确认 LaunchAgent 指向的实际程序目录；升级全局 npm 包不会自动替换自定义运行副本。同步计划与远端凭证由用户自行管理，安装包不会自动启用 SSH 或同步任务。
