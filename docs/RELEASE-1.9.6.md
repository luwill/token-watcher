# Token Watcher 1.9.6

本版本整合设备筛选、Windows 用量元数据同步，以及已合入主线的 PR #16–20。

- **设备用量**：仪表盘支持全部设备、本机、VPS、Windows 和未归属；趋势、模型、费用、会话、工具活动与 CSV 使用统一筛选范围，仍保留全部设备累计量。账户配额、余额和订阅 ROI 继续共享。
- **归属与去重**：首次启动增加设备元数据和索引，按可靠的来源路径、会话及文件标识归属历史记录；保留原 token 数、事件 ID 和去重键，模糊来源显示未归属。异步解析期间的本机轮询不会被远端上下文污染。
- **历史缓存整合**：历史汇总和费用缓存按数据库连接及设备分区隔离，设备总览也复用历史缓存；历史写入、外部提交与跨日失效，事务内读取和回滚保持正确。
- **Windows 同步辅助工具**：通过 SSH/SFTP 传输白名单用量元数据，哈希化标识，校验字段、路径和 SHA-256；不传输会话正文、项目真实路径、工具参数或凭证。源重写、压缩日志或下载失败会保留此前数据并报错。配置/诊断脚本需用户主动执行，不自动启用 SSH、同步任务或修改防火墙。
- **性能与扫描可靠性**：包含 #16 的首扫及长行复杂度优化、#17 的历史汇总缓存、#18 的事务缓存保护、#19 的 Codex 模型补齐优化、#20 的扫描期间请求补跑。
- **源码工具**：保留逐日用量导出和视频渲染 Python 脚本；生成的数据、视频、私人配置及旧版完整会话镜像工具不进入 npm 包。

最低 Node.js 版本保持 22.13，无新增 npm 依赖。验证包括 Node 22.13.1/24 完整离线回归、设备切换/缓存复用/事务回滚、跨设备重复采集、Windows 投影与实际采集器及 Store 的一致性，以及干净安装和三平台 CI。贡献者的性能测量不作为已在所有用户机器复现的保证。

升级前建议备份用量数据库。使用自定义 LaunchAgent 或独立运行目录的用户，应确认实际启动的程序路径；本版本不会自动替换已有自定义运行副本或同步配置。

安装：`npm install -g token-watcher@1.9.6`。
