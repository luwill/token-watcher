# v1.8.0 — 社区排行榜与升级可靠性修复

新增默认关闭的社区排行榜。顶部入口切换概览区域，支持今日（UTC）、滚动近 7 日和近 30 日；主力模型取所选周期内 Token 最多的模型，并保留完整版本名。

## 更新

- `token-watcher leaderboard on <昵称>` 显式加入，`off` 停止后续上报；仅发送聚合统计，不上传会话内容、文件路径或逐请求日志。
- 提供 Cloudflare Workers + D1 自托管后端、增量迁移和部署文档。
- 保留字昵称不会再覆盖 CLI 主命令；未知命令明确报错。
- Codex 旧路径去重键升级为文件名键，防止归档或重扫重复入账。
- “全部”范围包含完整历史，图表与 CSV 导出使用相同口径。
- 逐行读取回调失败后，扫描回滚当前文件并继续处理后续文件。
- 同步 package-lock 的包名、命令别名、Node 要求和版本元数据。

## 安装与升级

```bash
npm install -g token-watcher@1.8.0
token-watcher --version
```

支持 Node.js 22.13 及以上。升级前停止旧版后台进程，再从新版启动，避免不同版本同时写库。首次打开旧库会执行一次 Codex 键迁移；受影响原始行保存在同库 `codex_key_migration_backup`，迁移失败整体回滚。该归档不替代独立数据库备份。已有规范键记录及其他来源的用量不会重复累加。

排行榜数据由客户端自报，未经第三方验证；今日采用 UTC 日，近 7/30 日使用滚动窗口。旧客户端未上报的周期字段会显示待更新。

## 已知限制

- 本机端口冲突后自动重试可能重复启动后台轮询；遇到时使用明确的空闲端口，并避免同时运行多个服务。
- ROI 在模型缺少牌价时可能偏低；仅作参考，不作为账单。
- 首次采集失败且没有数据的来源可能显示为空；可检查本地解析错误日志。
- macOS 菜单栏的部分 Codex 配额展示仍使用旧字段，配额以网页面板为准。
- ECharts 5.6.0 存在中危 lines tooltip XSS 公告；当前图表没有使用 lines series。跨主版本升级及完整视觉回归留待后续版本。
