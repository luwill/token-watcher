# Token Watcher 1.9.8

- 新增豆包与豆包工作数据源。只读采集本机各个 Chromium 配置目录下的 IndexedDB，一次回复中每个上下文记录计为一次模型请求。
- 新增可配置用量告警。在面板顶部的「告警设置」中逐条调整阈值，网页显示告警横幅，菜单栏同步显示当前告警。
- 新增模型测速面板。按模型显示单次请求耗时与输出速度（中位数 / P90），全部从本地日志推算，不额外发请求。Claude Code 与 ccmr 为实测；Codex 日志没有请求发出时刻，按上一个事件推算，标「≈」。
- 升级后首次启动会重扫 Claude Code、ccmr、Codex 的历史日志以补全耗时，日志较大时可能需要几分钟，不会重复计数。
- 新增 qwen4-max 官方定价（阿里云百炼，人民币，每百万 token：输入 10、缓存命中 0.5、5 分钟缓存写入 12.5、输出 30）。

安装指定版本请运行 `npm install -g token-watcher@1.9.8`。最低 Node.js 版本为 22.13。
